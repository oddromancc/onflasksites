# Intro

This is a tutorial on making websites with Flask. It's made to be simple and teach just the working essentials so you can get started and feel confident building upon this foundation.

## Installation

Let's assume Python is already installed.

When starting any project, create a virtual environment. Later you will install packages, and it's good practice to have them contained in this environment which is usually initialized in a hidden folder titled `.venv/`. In your project folder run this in the terminal:
```
python -m venv .venv
```

Now activate your virtual environment by running this command in your terminal:
```
.\.venv\Scripts\activate
```

Install Flask with this terminal command:
```
pip install flask
```

You're all set for the next page.
